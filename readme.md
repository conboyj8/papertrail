## About The Project

**PaperTrail** is a web application and browser extension designed to connect fragmented research resources—such as academic papers, source code, datasets, and experiments—without requiring researchers to change their existing workflows. 

While a user reads a paper on platforms like arXiv or IEEE, PaperTrail automatically extracts key information and displays relevant connections, including official GitHub repositories, datasets, methodologies, and related research.

### Key Features
* **Seamless Extraction:** Automatically identifies and links papers to their official implementations and datasets.
* **Personal Library:** Save, search, and filter papers by title, topic, or shared methodology.
* **Connections:** Visualize connections between papers in your library that share datasets or methods.
* **AI Chat & Summarization:** Get quick AI-generated overviews of papers and interact with a context-aware chatbot to understand difficult sections.
* **Auto-Citation:** Generate citations instantly in preferred styles (APA, Harvard, IEEE, BibTeX).

## Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Backend:** Java, Spring Boot 4
* **Database:** MySQL
* **APIs & AI:** OpenAI API (`gpt-4o-mini`), Papers with Code API, Semantic Scholar, Crossref
